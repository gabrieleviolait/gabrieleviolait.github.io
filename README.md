Progetti principali
Offfice.it / Ufficio

Suite di strumenti online semplici, gratuiti e orientati alla privacy.

Include editor di testo, fogli di calcolo, strumenti di produttività, calcolatrici e utility web.
L’obiettivo è creare un piccolo ambiente di lavoro online leggero, accessibile e utilizzabile senza tracciamenti invasivi.

Repository e demo pubblica vengono aggiornati progressivamente.

GhostOS

Sistema operativo sperimentale scritto in Assembly/NASM.

È un progetto di studio avanzato su bootloader, kernel, rete, driver, memoria, debugging e architettura a basso livello.
Non è pensato come sistema operativo pronto all’uso, ma come laboratorio tecnico per esplorare il funzionamento interno di un OS.

ChatP2P

Prototipo di chat peer-to-peer con attenzione a comunicazione diretta, sicurezza e indipendenza da server centrali.

Il progetto è sperimentale e viene pubblicato con forte disclaimer: non va considerato software di sicurezza pronto per utilizzi critici senza revisione, audit e test approfonditi.

Plugin WordPress e strumenti web

Alcuni repository includono plugin, script e piccoli strumenti per WordPress, siti statici, traduzione, automazione, QR code, calcoli, firme email e utility quotidiane.

Sono progetti nati da esigenze pratiche e poi ripuliti per essere condivisi pubblicamente.

Approccio

Uso GitHub come spazio pubblico per:

documentare progetti reali;
condividere codice selezionato;
mostrare evoluzione tecnica;
separare ciò che è pubblicabile da ciò che deve restare privato;
costruire un portfolio tecnico trasparente.

Molti progetti nascono da un workflow ibrido tra sviluppo manuale, strumenti AI, test locali, VPS, automazioni e revisione diretta del codice.

L’uso di strumenti AI non sostituisce la progettazione, la revisione, la responsabilità tecnica o la comprensione del codice: è parte del processo di sviluppo, come acceleratore e supporto operativo.

Note su sicurezza e privacy

I repository pubblici non includono intenzionalmente:

chiavi API;
token;
file .env;
dati personali;
configurazioni private;
database personali;
credenziali;
contenuti non distribuibili;
codice non revisionato che possa esporre ambienti reali.

Quando necessario, i progetti includono disclaimer, licenze e note di utilizzo.
